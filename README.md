# Lumière Studio — Premium AI Image Upscaler Frontend

An upscale, editorial-grade luxury interface designed for high-end AI image enhancement and creative workflows.

## ✨ Features

- **Editorial Luxury Dark Aesthetics**: Modern glassmorphism, refined typography, and subtle micro-animations.
- **Interactive Before/After Slider**: Real-time visual comparison of upscaled vs original details.
- **Dynamic Control Panel**:
  - Model selection (HyperReal v4, DetailMax Neural, Cinematic Enhancer)
  - Scaling factors (2x, 4x, 8x)
  - Parameter fine-tuning (Denoise, Face Restoration, Texture Boost, HDR)
- **Live Output Queue & Analytics**: Job status tracking, batch processing monitor, and export options.
- **Responsive Layout**: Designed for seamless viewing across desktop and mobile devices.

## 🚀 Tech Stack

- **React 18**
- **Vite**
- **Lucide Icons**
- **Vanilla CSS** with a custom design token system

## 🛠️ Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed (v18+ recommended).

### Installation

```bash
npm install
```

### Development Server

Start the local Vite dev server:

```bash
npm run dev
```

Or run the bundled shortcut:
```bash
"Start Lumiere Studio.cmd"
```

### Production Build

```bash
npm run build
```
